About Tasha

Hi!I am originally from St. Louis, Missouri...the "Show Me State". While I love my hometown, I don't particularly like driving around in snow, so I currently live in Tallahassee, FL where I am about an hour and a half from the beach. I have experienced a lot of seasons of transition in my life and I am now transitioning into the technology space.

While I am fairly new to the coding world, I recently built a web app with the assistance of AI so I am incredibly excited to learn the why behind what I was creating in my app. I noticed how one character could shut down the whole page and it really intrigued me how something that seemed so minor could cause a major issue. That sparked my interest in learning coding for myself and here I am now building my first webpage on my own.

My CodeSquad Journey So Far

Here are the three modules that I enjoyed the most during the Code Squad Mini Course.

CSS Module

The CSS module was by far my favorite. Maybe it's because I'm from the "Show Me State" but I love being able to make things visually appealing so this module was right up my alley.

VS Code Module

I had VS Code installed already but was definitely not aware of its full capacity. I learned a lot from the tutorial about ways to get the most value out of VS Code going forward. I especially liked learning about AutoSave because that was something I wished it did when I was building my own app. I am excited to see how all of the extensions work moving forward.

Booleans & Numbers Module

I actually had a love/hate relationship with the Boolean and numbers module. It was very interesting to see how the code could work to help solve math problems but navigating the idea of truthy/falsy was a little challenging. While I have a little bit of a better understanding, I am looking forward to learning more about Boolean and its benefits.
